# 知情启用、最小健康记录与主人专属第一版

> 状态：历史输入；不再构成当前产品权威。其中“阻止诊断”的边界已由 [`健康管家真实上线与稳定运行路线`](../../.scratch/partner-health-steward/map.md) 和 [`确定诊断性判断与持证医生正式诊断之间的产品边界`](../../.scratch/partner-health-steward/issues/40-define-diagnostic-physician-handoff-boundary.md) 取代。

系统必须先向画像主人说明健康资料保存、周期性复盘、主动联系和数据权利，只有本人明确启用后才整体开启健康管家。启用后的普通对话可以自动提出健康记录候选，但只保存通过校验的结构化资料及其最小必要证据、来源和时间，不保存完整聊天；未成功写入时不得显示为已经记录。

正常健康处理之前保留一个不可绕过的窄范围危险闸门，用于明确急症、自伤风险、要求擅自改药或要求确定诊断等高风险情况。命中后优先给出安全回应并阻止诊断、擅自改药等禁止动作；画像主人的原始陈述仍可按普通证据规则入档，但闸门判断本身不能形成诊断或主动任务。它不是通用健康分类器，也不预先认可旧关键词实现。

第一版只向画像主人提供健康资料的查看、纠正、导出和删除能力，不实现第三方健康内容查看。这样减少首版授权面和隐私风险；分享能力若以后需要，必须作为新的产品决定单独设计。
