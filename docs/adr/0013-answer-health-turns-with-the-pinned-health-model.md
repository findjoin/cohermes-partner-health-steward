# 用固定健康模型回答健康相关轮次

> 状态：已由 ADR 0014 取代，仅保留为决策历史。

健康相关微信轮次在认证、独立判别和候选接纳后，从 sidecar 以一次性本轮收据读取最新 300 字画像、相关证据 ID 和新鲜资料卡摘要，再由独立固定的健康模型 fresh 调用生成回答。该轮次不进入普通对话模型、普通 Hermes 会话历史或普通文本合批；普通聊天继续走原生 Hermes 且不接收健康正文。一旦分类已确认当前消息健康相关，后续签名、入档、上下文、资料或回答的异常与超时都只能走固定健康失败回复，不能再回退普通聊天。这样放弃普通会话连续性，换取健康数据接收方固定、上下文最小化和 post-write 当前版本一致性。

本决定取代 ADR 0009 中“把健康上下文注入本轮普通对话模型”的措辞；ADR 0009 的普通轮次零健康上下文和 memory 最小化边界继续有效。

自动判别与健康回答复用同一个固定调用边界和独立配置。日检与到期渲染的生产模型、资料和渠道端口由 Ticket 23 单独完成并验收，不属于本决定的实现声明。
