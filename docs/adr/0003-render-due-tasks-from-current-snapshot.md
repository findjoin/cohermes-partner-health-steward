# 到期任务在当前受控快照上渲染

> 状态：当前快照与发送/跳过原则继续有效；ADR 0014 已将快照来源从 sidecar 改为插件专用健康数据库，并由当前 Partner Hermes 完成判断。

未来派生任务只持久化任务目的、证据引用、时间窗和策略约束。到期后由固定派发 Job 在 fresh session 中通过 sidecar 读取当前授权快照，再调用 LLM 生成文案或跳过；它不自动继承微信会话历史，也不能在此过程中创建新的 Cron。

Hermes 仍会为该 fresh session 组装系统身份、技能索引、工具 schema、Cron prompt 与运行时信息；原生 Cron 默认不加载 Memory。按 ADR 0014，健康插件另以只读入口提供当次 `USER.md` 用户理解，并从专用健康数据库提供当前健康快照。健康快照是画像和任务是否仍成立的唯一健康状态权威；`USER.md` 只能影响交流方式，不能单独形成或改写健康结论。
