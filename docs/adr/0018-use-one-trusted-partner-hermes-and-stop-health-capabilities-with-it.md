# 由一个可信 Partner Hermes 统一推理并与其同生共停

> 状态：由 ADR 0021 统一继承并修订。以下正文只保留为历史输入，不再单独构成当前技术路线权威。

健康对话、周期性复盘和主动提醒判断均由同一个 Partner Hermes 使用其当前模型和供应商完成，不建立第二个健康 Agent、独立健康模型或 Hermes 停机后仍继续行动的后台健康服务。Partner Hermes 及其经审核的健康组件属于同一个可信应用边界；系统不承诺抵抗已能在同一系统账户执行的恶意代码或服务器最高权限，而是重点防止未授权身份、重放、模型错误和磁盘泄露。

当前模型供应商是健康数据接收方，必须在首次启用时向画像主人说明。接收方发生变化时，健康处理不能自动迁移，必须重新取得本人同意。Partner Hermes 离线期间健康复盘和主动联系停止；恢复后只根据当前状态重新评估，不逐条重演或补发历史行动。
