# 建立由单一主人控制的非诊断性主动健康管家

> 状态：历史输入；不再构成当前产品权威。“完全不诊断”的边界已由 [`健康管家真实上线与稳定运行路线`](../../.scratch/partner-health-steward/map.md) 和 [`确定诊断性判断与持证医生正式诊断之间的产品边界`](../../.scratch/partner-health-steward/issues/40-define-diagnostic-physician-handoff-boundary.md) 取代。

健康管家服务一位画像主人。经本人明确启用后，它维护可追溯的长期健康资料、回答健康问题、周期性复盘，并可以主动询问或提醒；男朋友、家人、管理员和服务器所有者均无默认查看或控制权。

健康管家提供一般健康知识、生活方式支持和就医准备，但不诊断、不排除疾病、不替代医生，也不擅自建议开始、停止或调整处方药；明显危险时建议及时联系急救或就医。这个边界保留长期主动支持的价值，同时避免把产品变成医疗诊断或持续监护系统。
