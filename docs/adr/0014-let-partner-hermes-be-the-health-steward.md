# 由 Partner Hermes 本身扮演健康管家

> 状态：已由 ADR 0015 取代，仅保留为上一轮明确决定的历史记录。

本 ADR 曾取代 ADR 0001、0005、0006、0008、0009、0011 和 0013 的 sidecar、独立判别模型、独立健康模型及签名服务路线。

Partner Hermes 是面向画像主人的唯一健康管家人格，也是实时健康对话、每日复盘和到期任务判断的唯一 LLM 使用者。健康管家插件没有自己的 LLM、供应商配置或独立对话入口；它只向同一个 Hermes 提供结构化健康档案、证据、资料、任务和控制工具。Cron 的 fresh session 是 Partner Hermes 的新执行上下文，不是第二个健康 Agent。

健康管家启用后，Partner Hermes 在正常对话中自主判断是否调用健康工具，不再为每条消息并行调用独立分类模型。插件只有在候选结构合法且证据可追溯时才写入；成功才显示画像已更新，失败时正常对话可以继续但必须明确说明本次未记录。

健康画像、证据簿、资料卡、派生任务和投递状态由插件直接管理的本地专用数据库持有，不再部署独立 health sidecar、Unix socket、独立服务账户或进程间签名服务。Partner Hermes 的原生 `USER.md` 继续独立维护对用户的一般理解和交流偏好，不能充当第二份健康数据库。普通聊天按需调用健康工具；原生 Cron 默认跳过 Memory，因此两个健康 Cron 通过插件提供的只读入口取得当前 `USER.md`，不能借此修改原生 Memory，也不把健康事实双写进去。

Partner Hermes、其微信适配层和经审核的健康插件共同构成可信应用边界。系统仍必须校验主人身份与同意、约束工具输入、保存证据、控制查看与删除、到期重读当前状态，并保证任务和微信投递幂等；但不再声称抵抗已经能以同一 Hermes 系统身份执行的恶意代码。因此不采用 Job 专属密钥、Job 指纹、same-UID broker、独立 receipt signer 或 Hermes core patch。

Hermes 只保留两个固定原生 Cron Job：日检用 fresh Hermes 会话产生 `no_action` 或候选任务，派发器用 fresh Hermes 会话读取插件数据库中的到期任务并基于当前快照决定发送或跳过。派生任务不各自创建 Cron。Hermes 或 Gateway 离线时健康能力停止；恢复后，多次错过的日检折叠为一次面向当前画像的复盘。未到时间窗的任务继续等待，仍在窗口且依据有效的任务重新判断，过窗或失效任务跳过，不集中补发历史消息。

日检不使用固定任务类型枚举，而是让 Partner Hermes 自主回答两个问题：画像还缺什么，以及应询问画像主人还是查阅资料；基于当前画像是否应建立定时任务。主动联系不设置每日次数、固定安静时段或同主题退避，交流偏好沿用 Partner Hermes 已有的用户理解；插件只阻止同一任务因重试而重复投递。画像由 Hermes 自主维护，不要求每周人工核对，也不默认发送周报；画像主人仍可随时查看、纠正或明确订阅变化摘要。

健康能力跟随 Partner Hermes 当前模型和供应商。模型或供应商变化会同时改变健康行为和健康数据接收方，必须向画像主人说明并重新验证，但不维护第二份健康模型配置。该选择换取一个人格、原生对话连续性和更简单的部署，接受健康数据不再与可信 Partner Hermes 进程隔离、健康行为不再独立于 Partner 模型配置的代价。

画像主人询问健康档案时，由同一个 Partner Hermes 按需读取健康数据库并自然回答；当前获授权查看者也可获得只读自然回答。只有正式 JSON 导出由插件确定性生成，且只允许画像主人导出。这取代“完整查看必须绕过聊天 LLM”的旧路线，因为当前 Hermes 本身就是已授权健康管家。

健康插件不启动独立的十分钟日检重试器。Partner Hermes 正常模型请求的瞬时重试结束后，当次日检若仍失败，只记录无健康正文的失败结果，交下一次日检或恢复追赶处理。微信发送结果不确定时仍禁止盲目重发。

健康插件不部署独立监控服务、dead-man 心跳或故障邮件；故障通过 Hermes 原有服务状态、Cron 运行记录和系统日志呈现。整机监控属于可另行建设的通用运维能力。

永久删除清除插件健康数据库中的画像、证据、版本、任务、授权、投递状态和可解密备份，但不冒充删除微信原始消息、Hermes 普通会话历史或 `USER.md` 中非健康的一般用户理解；执行前必须向画像主人说明该边界。

ADR 0003 的“到期前读取当前快照”、ADR 0007 的幂等微信投递，以及 ADR 0010 的本人同意与恢复继续有效；其中原有 `sidecar` 或“独立健康模型”实现措辞均按本 ADR 改由插件专用数据库和当前 Partner Hermes 实现。ADR 0012 的“完整查看绕过聊天 LLM”已被本决定取代，仅保留确定性导出原则。
