# 每条主人消息均检查健康内容并写入独立权威档案

> 状态：由 ADR 0021 统一继承并修订。以下正文只保留为历史输入，不再单独构成当前技术路线权威。

健康管家启用后，同一次 Partner Hermes 对话必须检查每条可信主人消息是否包含值得记录的健康内容，不依赖模型偶然选择工具，也不增加第二个分类模型。只有通过证据和结构校验的健康记录候选进入独立的结构化健康档案；普通聊天历史和 `USER.md` 都不能充当健康档案或保存未接纳全文。

任何健康写入和主人控制操作都必须绑定由渠道适配层提供的渠道、发送者 ID、消息 ID 和接收时间，并在合批过程中保持逐条来源。来源不完整时普通对话可以继续，但健康写入和主人控制失败关闭。这个选择增加了入站集成要求，以换取可追溯、防重放且不会静默漏记的长期档案。

同一画像主人可以使用多个由本人明确绑定的私聊渠道访问同一健康档案。未绑定身份和群聊都不能读取、写入或控制健康资料；跨渠道能力不把单一主人产品扩张成多人共享档案。
