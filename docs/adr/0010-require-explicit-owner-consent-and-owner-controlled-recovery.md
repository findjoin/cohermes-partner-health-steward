# 要求主人明确启用并由主人控制身份恢复

> 状态：部分被后继 TO 取代。现行知情初始化由 Tickets 53、74 承接；恢复码与聊天身份迁移退出首发目标；“当前模型供应商”由 Ticket 58 的首跳模型服务路线边界取代。以下正文作为历史决定保留。

健康画像不会因首条健康消息、伴侣关系或服务器所有权自动启用。Partner Hermes 必须先说明健康资料保存、每日复盘、主动微信、当前模型供应商、查看、暂停和删除边界；预配置主人随后明确回复“启用健康管家”，才同时开启健康记录、每日复盘和主动关心。主人可以单独暂停主动关心，也可以停止新记录而保留已有加密档案。

身份更换只能由旧身份迁移或使用只交给主人、用后轮换的恢复码，管理员和查看者不能替主人授权重绑。
