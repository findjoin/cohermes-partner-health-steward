# Domain Docs

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read ADRs relevant to the work under `docs/adr/` when they exist.
- When these files do not exist, continue silently. Create them only when a later domain-modeling stage resolves a term or an architectural decision.

## Layout

This is a single-context repository. The canonical domain glossary is root `CONTEXT.md`; architecture decisions live in `docs/adr/`.

## Vocabulary and conflicts

Use terminology defined in `CONTEXT.md`. If an output conflicts with an ADR, state that conflict explicitly rather than silently overriding it.
