# 21 — 提供主人导出与二次确认删除

**What to build:** 让画像主人可以获得不经过普通聊天模型的完整 JSON 微信附件，并能在十分钟内二次确认永久删除；删除立即撤销有效健康访问并销毁记录密钥，同时准确说明无法召回的外部副本边界。

**Blocked by:** 20 — 通过微信完成主人控制、查看者授权和私密查看

**Status:** resolved

- [x] 只有画像主人能请求完整 JSON 导出；查看者、管理员和未认证 sender 均不能导出。
- [x] 导出内容由 sidecar 直接生成并作为幂等微信附件发送，不进入普通聊天 LLM 或普通 Hermes 会话历史。
- [x] 导出明文只创建在严格权限的私有 tmpfs 中，确认发送后立即删除；异常遗留文件最迟 24 小时清理。
- [x] 永久删除必须由主人当前轮发起，并在十分钟内使用第二份动作绑定收据确认；超时、重放、参数不一致和单次表达均不删除。
- [x] 删除覆盖当前画像、版本、个人证据、任务、报告、授权、投递状态和 memory 投影，并立即销毁记录专用密钥，使受管理备份不可解密。
- [x] 加密备份残留在 30 天内物理清理；只保留 90 天无内容删除审计，不保留健康正文。
- [x] 微信和普通 Hermes 聊天历史以及已发送或已导出的外部副本不在删除范围内，系统不得声称已经召回。
- [x] 主验收覆盖导出发送与清理、查看者拒绝、二次确认、删除后访问阻断、备份不可解密和无内容审计。
