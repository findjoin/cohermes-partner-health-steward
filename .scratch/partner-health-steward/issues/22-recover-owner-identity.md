# 22 — 提供主人控制的身份恢复

**What to build:** 让画像主人在微信 sender 身份更换或丢失时，只能通过旧身份迁移或一次性高熵恢复码重绑定健康档案；恢复能力不赋予服务器管理员或查看者任何内容或身份控制权。

**Blocked by:** 20 — 通过微信完成主人控制、查看者授权和私密查看

**Status:** resolved

**Answer:** 已实现旧身份迁移与一次性恢复码重绑定；恢复码仅以 HMAC verifier 保存，成功后轮换并撤销旧主人控制权。定向恢复码测试 `5/5` 通过，完整健康管家单测 `501` 项通过、`25` 项跳过；当前项目未配置类型检查器，环境中也没有 `mypy` 或 `pyright`。代码审查：Standards 0 项，Spec 0 项。

- [ ] 初次启用时生成高熵恢复码并只向画像主人显示一次；日志、审计、普通会话历史和部署输出不保留明文。
- [ ] sidecar 只保存恢复码 verifier/hash，不保存可读取明文；恢复验证使用受控次数和无内容失败审计。
- [ ] 主人可由仍有效的旧身份明确迁移到新 sender ID，或由新身份提交一次性恢复码完成重绑定。
- [ ] 恢复成功立即作废旧恢复码、轮换新码并撤销旧身份后续控制权；并发或重复使用只能有一次成功。
- [ ] 查看者、服务器管理员、定时任务和模型不能签发、查看或代用恢复码，也不能直接修改主人绑定。
- [ ] 旧身份和恢复码都不可用时恢复失败关闭，不提供基于服务器所有权或关系身份的后门。
- [ ] 恢复不改变档案内容、证据、授权或删除状态，只改变经验证的主人控制身份并留下无内容审计。
- [ ] 主验收覆盖旧身份迁移、恢复码成功与轮换、重复/并发使用、管理员和查看者拒绝以及不可恢复状态。
