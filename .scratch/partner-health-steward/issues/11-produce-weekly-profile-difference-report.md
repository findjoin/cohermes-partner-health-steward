# 11 — 实现周度画像差异报告

**What to build:** 让日检每周为获授权查看者生成一次可追溯的画像变化摘要，而不创建第三个 Cron 或复制完整健康档案。

**Blocked by:** 06 — 实现主人自查、查看授权与只读访问；08 — 实现每日画像复核与派生任务规划；09 — 实现到期快照渲染与消息派发；10 — 实现主动触达治理

**Status:** resolved

- [x] 日检创建一个周日 10:00 到期的画像差异派生任务，时间按画像主人时区解释。
- [x] 报告比较相邻画像版本，列出画像增删改、证据新增或撤销、任务发送/跳过/失败、授权/删除操作和日检失败。
- [x] 报告正文只含变化摘要和可追溯引用，不复制完整画像、证据正文或聊天历史。
- [x] 报告通过现有派发器到期渲染，不创建第三个原生 Job。
- [x] 只有有效完整查看授权的指定查看者能够收到报告；撤权或删除在发送前阻断报告。
- [x] 没有实质变化时允许生成明确的无变化摘要或 `skip`，不能伪造变化。
