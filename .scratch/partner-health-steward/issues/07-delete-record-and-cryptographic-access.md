# 07 — 实现删除、密钥销毁和 memory 投影清理

**What to build:** 让画像主人能够真正删除健康档案，使当前数据、历史版本、任务、memory 投影和备份访问能力在规定时间内消失，同时只保留无健康内容的删除证明。

**Blocked by:** 06 — 实现主人自查、查看授权与只读访问

**Status:** resolved

- [x] 每个主人健康档案使用独立数据加密密钥，密钥不进入模型上下文或普通 Hermes 配置。
- [x] 主人删除请求立即删除画像、画像版本、个人证据、授权和未完成任务，并取消等待中的触达。
- [x] 删除立即销毁该档案的独立密钥，使活动存储和历史加密备份中的档案不可解密。
- [x] 普通 Hermes memory 中只存在 sidecar 单向生成的档案指针和授权长期偏好，删除后该投影同步移除。
- [x] 删除后仅保留不含健康正文的删除事件，并遵守 90 天无内容审计保留期。
- [x] 可控备份时钟证明加密旧副本最迟在第 30 天物理清理，且清理前也无法因密钥销毁而解密。
- [x] 删除不会移除与个人档案无关的共享权威资料卡。
