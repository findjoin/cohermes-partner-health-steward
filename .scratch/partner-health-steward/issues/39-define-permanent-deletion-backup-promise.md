# 【TO】确定主人永久删除健康画像的产品结果与边界

Type: grilling
Status: resolved
Parent: [健康管家首发 TO、CAN 与 HOW 决策闭合路线](../map.md)
Blocked by: None

## Question

主人要求永久删除健康档案时，健康管家在产品层面必须做什么？

## Answer

主人明确要求永久删除健康档案后，Hermes 删除这份健康档案。删除完成后，健康管家不得再读取、推断、复盘、主动联系或恢复其中的内容。

这就是完整的产品要求，不增加删除倒计时、固定清除期限、删除回执、失联自动清理、管理员代删或其他独立产品功能。服务器上健康档案具体对应哪些文件或持久化数据、如何执行和验证删除，留给后续 CAN、HOW 与验收阶段按照实际 Hermes 架构确定。
